Support: Run That Back

Run That Back, by Draftworthy. Don't read it. See it.

How to play

A color word appears in the wrong ink. Tap the color of the ink, not the word the letters spell. The first card of every run is the signature: the word BLUE printed in green. The correct tap is GREEN.

Modes

Chill (learn it), Classic (full pressure), and Chaos (the rule can flip mid-run, so watch the on-screen rule banner). You have three hearts per run; streaks build combo multipliers up to x5.

The Daily Challenge

One run per day, identical for every player. Your Daily history is kept on your device.

Friend challenges

After any run you can copy a challenge link or code and send it to a friend. Opening it deals them your exact run with your score as the target.

Your scores

Best scores and Daily history live only on your device. Use "clear saved scores" in the game for a clean slate; uninstalling also removes them.
